## 🔧 EASY CUSTOMIZATIONS

### Change Colors (1 minute)
Edit `styles/main.css` `:root` section:
```css
--electric-cobalt: #0080FF;  ← Change this
```

### Change Company Name (30 seconds)
Edit `index.html` find `.logo-text`:
```html
<span class="logo-text">YOUR-NAME</span>
```

### Change Headline (30 seconds)
Edit `index.html` find `.hero-title`:
```html
<h1 class="hero-title">YOUR HEADLINE</h1>
```

### Update Email/Phone (1 minute)
Edit `index.html` find `.contact-link`:
```html
<a href="mailto:your@email.com">your@email.com</a>
```
